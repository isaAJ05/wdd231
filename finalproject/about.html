About BookVerse

BookVerse is a simple reading discovery app built for the WDD 231 final project. It uses the Google Books API to search titles, show details, and let users save favorites locally.

What You Can Do

Search Books

Find books by title, author, or keyword with live API results.

Save Favorites

Keep track of books you like using localStorage in your browser.

Explore Categories

Browse featured categories and open detailed book cards in a modal.
